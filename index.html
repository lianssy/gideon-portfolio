01 / Capabilities

A personal workspace for thinking and building.

Gideon is being developed in small, testable steps: useful memory and organization first, with a simple local interface that stays out of the way.

◈

Persistent memory

Save specific facts when you explicitly ask Gideon to remember them, then retrieve them in future conversations.

▤

Saved conversations

Store chat history locally and return to earlier conversations instead of starting from zero each time.

⌘

Projects & tasks

Create project records, add tasks, list what's in progress, and mark tasks complete.

⌕

Read-only file helper

Read supported text and code files inside Gideon's project directory when explicitly requested. It does not execute those files.

◎

Local model connection

Uses Qwen 2.5 7B through Ollama running on the computer, rather than requiring a hosted model API for chat.

✧

Midnight terminal UI

A black starfield, restrained silver accents, readable chat bubbles, and a focused workspace layout.

03 / Get started

Try the early-access build.

Download the source bundle, set up the required local runtime, and launch Gideon in its own desktop window. This preview is for people comfortable following setup steps.

Windows 10/11Python 3.14OllamaQwen download required
Download source preview ↓

ZIP source bundle · Not an installer

STEP 01

Install the prerequisites

Install Python for Windows and Ollama. During Python setup, enable the Python launcher if offered.

STEP 02

Set up the preview

Extract the ZIP into a folder you control. Double-click Setup_Gideon.bat. Then open PowerShell in that folder and run ollama pull qwen2.5:7b. The model download is several gigabytes.

STEP 03

Launch Gideon

After setup and model download finish, double-click Launch_Gideon_Desktop.bat. Keep Ollama installed and running. Your conversation data is stored in the local data folder.

Important: this early-access package is source code and setup scripts, not a signed installer. It requires Python, Ollama, and the Qwen model. Do not upload your personal database, virtual environment, or private chats when sharing or publishing your own copy. A one-click Windows installer is planned for a later release.
